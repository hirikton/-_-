## Цель работы

Закрепить навыки, полученные на парах:

1. Создание семантической структуры HTML-документа.
2. Работа с формами и валидацией.
3. Создание и стилизация таблиц.
4. Вставка мультимедиа (изображения, видео, аудио).
5. Единый стиль оформления.

## Задание: «Личный кабинет студента»

Создайте многостраничный сайт **«Личный кабинет студента»** с тремя страницами:

| Страница        | Название   | Содержание                                        |
| --------------- | ---------- | ------------------------------------------------- |
| `index.html`    | Главная    | Профиль студента, навигация, форма обратной связи |
| `schedule.html` | Расписание | Таблица с расписанием занятий                     |
| `gallery.html`  | Галерея    | Изображения, видео, аудио                         |

## Требования к страницам

### Страница 1. `index.html` — Главная

**Обязательные элементы:**

1. **Семантическая структура:**
   - `<header>` с именем студента и группой.
   - `<nav>` с 3 ссылками на страницы сайта.
   - `<main>` с содержимым.
   - `<footer>` с копирайтом и контактами.

2. **Секция «Профиль студента»:**
   - Изображение студента (`<img>`) с атрибутами `alt`, `width`, `loading="lazy"`.
   - Список навыков (`<ul>`) — минимум 5 пунктов.
   - Список целей (`<ol>`) — минимум 3 пункта.

3. **Секция «Форма обратной связи»:**
   - Поля: имя (`text`, required), email (`email`, required), тема (`text`, required), сообщение (`textarea`, minlength=10), согласие (`checkbox`, required).
   - Валидация на все поля.
   - Группировка через `<fieldset>` и `<legend>`.

4. **Стилизация:**
   - Единый стиль: цвета, шрифты, радиусы, тени.
   - Hover-эффекты на ссылках и кнопках.
   - Адаптивность для мобильных (минимум 1 media query).

### Страница 2. `schedule.html` — Расписание

**Обязательные элементы:**

1. **Семантическая структура:**
   - `<header>`, `<nav>`, `<main>`, `<footer>` — как на главной.

2. **Таблица расписания:**
   - Столбцы: День недели, Время, Предмет, Преподаватель, Аудитория.
   - Минимум 10 строк с данными.
   - Использовать `<thead>`, `<tbody>`, `<tfoot>`.
   - Использовать `colspan` для заголовка таблицы.
   - Использовать `rowspan` для объединения ячеек по дням.

3. **Стилизация таблицы:**
   - `border-collapse: collapse`.
   - Чередование строк через `:nth-child(even)`.
   - Hover-эффект для строк.
   - `tfoot` с итоговой строкой (например, «Всего пар: 10»).

4. **Секция «Заметки»:**
   - Форма добавления заметки: текст (`textarea`, maxlength=200), дата (`date`), приоритет (`select` с 3 опциями).
   - Валидация на поля.

### Страница 3. `gallery.html` — Галерея

**Обязательные элементы:**

1. **Семантическая структура:**
   - `<header>`, `<nav>`, `<main>`, `<footer>` — как на главной.

2. **Секция «Фотогалерея»:**
   - Минимум 6 изображений с атрибутами, `alt`, `width` `loading="lazy"`.
   - Каждое изображение — в `<figure>` с `<figcaption>`.

3. **Секция «Видео»:**
   - Видео с атрибутами `controls`, `poster`, `width`.
   - Минимум 2 источника `<source>` (MP4 + WebM).

4. **Секция «Аудио»:**
   - Аудио с атрибутами `controls`.
   - Минимум 1 источник `<source>`.

5. **Стилизация:**
   - Единый стиль с остальными страницами.
   - Галерея в виде сетки (можно через `display: flex` или `display: grid`).
   - Hover-эффекты на изображениях.
